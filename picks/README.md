# picks/ — 每日選股清單存檔與當沖回測

- `picks/<資料日>.json`：當天收盤後鎖定的清單（150 檔追蹤股的支撐壓力價位）。
  `date` 是**資料日（收盤日）**，`generatedFor` 是這份清單要用的**下一個交易日**。
  檔案一旦建立就不覆蓋。
- `daytrade_check.csv`：逐檔明細（對象日,來源清單日,代號,名稱,開,高,低,收,s1,s2,r1,規則,是否進場,進場價,出場價,報酬含成本%）
- `daytrade_summary.csv`：每日彙總（對象日,來源清單日,清單檔數,規則,筆數,勝率%,平均報酬%,最大單筆虧損%）
- `daytrade_summary.json`：各規則累計統計＋最近 10 個交易日逐日數字

價位欄位：`s1` 近端支撐、`s2` 第二支撐、`r1` 第一壓力、`r2` 第二壓力、`tol` 容差%。
每個價位是 `{v, lo, hi}`（參考值與價格帶）。沒有算出的價位為 `null`，不補假值。

## 回測規則（當沖，只用前一交易日清單裡已鎖定的價位，不用當天才知道的資料反推）
- A 買第一支撐：最低 ≤ s1.hi 視為碰到，以 s1.v 成交；最低 < s2.lo 以 s2.lo 停損，否則收盤出。
- B 買第二支撐：最低 ≤ s2.hi 視為碰到，以 s2.v 成交；停損 = 進場 × 0.985，否則收盤出。
- C 突破第一壓力追價：最高 ≥ r1.v 以 r1.v 成交，收盤出。
- D 不進場（對照組）：報酬 0。

成本每筆：買賣手續費各 0.1425%×0.6 ＋ 當沖證交稅 0.15%，已從報酬扣除。

資料來源：`/.netlify/functions/pp-status?csv=pred`（交易所公開資料推算）。
日線看不出盤中先後順序，停損／停利是否真的成交無法確認。

**僅供學習與統計參考，不是投資建議。**
